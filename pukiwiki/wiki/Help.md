# ヘルプ

PukiWikiMD のページは CommonMark と [GitHub Flavored Markdown](https://github.github.com/gfm/) です。詳しい一覧は [[FormattingRules|書き方]] にあります。

## ページを編集する

1. 読みたいページを開く
2. 上部の「編集」を押す（初回ログインは `editor` / `editor`。必ずパスワードを変えてください）
3. Markdown を書いて「更新」する

凍結されたページは編集できません。管理者は「凍結解除」を使います。凍結はファイル先頭の front matter `frozen: true` です。

## 新しいページ

本文に `[[新しいページ]]` と書くと、まだ無いページへのリンクになります。そこから編集画面を開けます。階層は `[[Manual/Install]]` のように `/` で区切り、ディスク上は `Manual/Install.md` になります。

## リンク

- この Wiki のページ: `[[ページ名]]` または `[[ページ名|表示文字]]`
- 外部サイト: `[表示](https://example.com/)` または URL をそのまま書く
- 見出しへのリンク: `[[ページ名#見出し]]`

## OGP

URL だけの段落、または URL だけの箇条書きは、**閲覧時**にタイトル・説明・画像のカードを出します。編集中のテキストエリアとプレビューでは取得しません。

```
https://example.com/
```

上のようにコードブロックの中に書いた URL はカードになりません。

取得結果は `cache/ogp/` に保存します。非公開アドレスや localhost へは取りに行きません。1ページあたりの枚数には上限があります。

## ファイル

ページ本文は `pukiwiki/wiki/` 以下の `.md` です。`:` などファイル名に使えない文字は `~3A` のように置き換わります。
